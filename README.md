## 🚀 How to Run

### PowerShell version (`.ps1`)
1. Right-click `HDD-MasterTool.ps1` → **Run with PowerShell**  
   *(or open PowerShell as Administrator and run it)*
2. If blocked by execution policy, run this first:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   ```

### Batch version (`.bat`)
1. Right-click `HDD-MasterTool.bat` → **Run as Administrator**

> ⚠️ **Administrator privileges required** for most features.

## 📋 Features — 16 Tools in One Menu

| # | Tool | Description |
|---|------|-------------|
| 1 | **Drive Overview** | Disk space, labels, file systems with visual bar |
| 2 | **Health Check** | SMART status, media type, bus type |
| 3 | **Disk Cleanup** | Clears Temp, Prefetch, WU cache, Recycle Bin |
| 4 | **Drive Optimization** | Defrag (HDD) or TRIM (SSD) auto-detection |
| 5 | **Partition Manager** | View partitions via Disk Management GUI |
| 6 | **File System Check** | CHKDSK with full scan options |
| 7 | **Disk Usage Analyzer** | Top 10 largest files/folders |
| 8 | **Volume Shadow Copies** | List, create, and delete VSS snapshots |
| 9 | **Disk Cloning & Backup** | Robocopy mirror, system image, backup wizard |
| 10 | **Disk Imaging** | Full Windows system image backup |
| 11 | **Secure Erase** | Free space wipe or full drive format |
| 12 | **Safety Checklist** | Pre-work drive safety check |
| 13 | **Disk Benchmarking** | Sequential read/write speed test |
| 14 | **Advanced Tools** | Recovery tools, TestDisk/PhotoRec downloader |
| 15 | **Reports & Logs** | Export drive report to file |
| 16 | **Emergency Triage** | Quick first-response disk diagnostics |
